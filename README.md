# Nova AI — Next-Gen AI Assistant

Nova AI is a sleek, ultra-fast, multi-model AI assistant powered by Puter.js and modern web standards.

Live Site: [https://kiddokavin.github.io/novaai/](https://kiddokavin.github.io/novaai/)

## Features

- 🧠 **Multi-Model Intelligence**: Switch seamlessly between **Claude 3.5 Sonnet**, **GPT-4o**, **DeepSeek V3**, and **Gemini 2.0 Flash**.
- 🎨 **Text-to-Image Generation**: Built-in AI artwork creation via Puter AI (`puter.ai.txt2img`).
- 💻 **Syntax Highlighting & Markdown**: Full GFM support, styled code blocks with copy snippet buttons, and math formatting.
- 🎙️ **Voice & Speech**: Voice dictation (Speech-to-Text) and audio response playback (Text-to-Speech).
- 💾 **Local Chat History**: Persistent chat sessions saved securely in browser `localStorage`.
- 📱 **Responsive Design**: Custom dark-mode UI with glassmorphism, responsive sidebar drawer, and fluid typography.
- 📤 **Chat Export**: Export conversations to Markdown files.

## How to Deploy to GitHub Pages

1. Initialize Git (if not already initialized in your project folder):
   ```bash
   git init
   git remote add origin https://github.com/kiddokavin/novaai.git
   ```

2. Add and commit files:
   ```bash
   git add index.html README.md
   git commit -m "Fix truncated HTML and launch complete Nova AI multi-model web app"
   ```

3. Push to your main branch:
   ```bash
   git branch -M main
   git push -u origin main --force
   ```

4. Verify deployment on [https://kiddokavin.github.io/novaai/](https://kiddokavin.github.io/novaai/).
